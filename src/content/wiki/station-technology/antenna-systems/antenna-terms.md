## 一、天线缩语：考试与通联里最常见的七个词

&emsp;&emsp;业余无线电里谈天线，大量使用缩写。这些缩写来自英文，多用于 CW 和口语通联，也是题库的常见考点。

| 缩写 | 英文 | 中文 | 指什么 |
| --- | --- | --- | --- |
| DP | dipole | 偶极天线 | 两臂对称、中心馈电，全长约半个波长 |
| GP | ground plane | 接地平面天线 | 四分之一波垂直振子加水平地网，常见于 VHF/UHF |
| VER | vertical | 垂直天线 | 振子垂直于地面，辐射垂直极化 |
| LW | long wire | 长线天线 | 长度远大于半波长的单根导线，常用于接收 |
| YAGI | Yagi-Uda | 八木天线 | 主振子加引向器、反射器的定向天线 |
| BEAM | beam | 定向天线（波束天线） | 有明确最大辐射方向的旋转式天线 |
| EL | element | 单元、振子 | 八木天线上的每一根金属杆都叫一个单元 |

&emsp;&emsp;其中「单元」用得最灵活：说「几单元八木」，指的就是主振子、引向器和反射器的总根数；说「单元间距」，指的是相邻两根金属杆之间的距离。

## 二、结构与部件

| 术语 | 英文 | 说明 |
| --- | --- | --- |
| 振子 | element / radiator | 天线上真正参与辐射的导体 |
| 主振子 | driven element | 直接接馈线、被发射机驱动的那个单元 |
| 引向器 | director | 八木天线中比主振子短、放在辐射方向前侧的单元 |
| 反射器 | reflector | 八木天线中比主振子长、放在后侧的单元 |
| 馈电点 | feed point | 天线与馈线连接的位置，位置不同输入阻抗不同 |
| 加感线圈 | loading coil | 给短天线补感抗、抵消容抗用的电感 |
| 地网 | radial / ground system | 垂直天线脚下的水平或埋地导线，提供回流路径 |
| 巴伦 | balun | 平衡—不平衡变换器，接在平衡天线与同轴电缆之间 |
| 扼流圈 | choke | 阻挡馈线外皮上的共模电流，不承担阻抗变换 |
| 天调 | ATU (antenna tuner) | 把天线阻抗变换到发射机认得的 50 Ω |
| 假负载 | dummy load | 50 Ω 无感电阻，用于不发射地测试电台 |
| 天线分析仪 | antenna analyzer | 扫频测量阻抗、驻波与谐振点的仪表 |
| 磁环天线 | magnetic loop | 周长远小于波长的环，靠磁场耦合辐射，适合小空间 |

## 三、电性能参数

| 术语 | 英文 | 说明 |
| --- | --- | --- |
| 波长 | wavelength | $\lambda = 300 / f$（f 以 MHz 计） |
| 谐振 | resonance | 输入阻抗的电抗部分为零的状态 |
| 电抗 | reactance | 阻抗的虚部，储存而不消耗能量 |
| 阻抗 | impedance | 馈电点电压与电流之比，复数形式 $Z = R + jX$ |
| 驻波比 | SWR | 馈线上电压波腹与波节之比，越接近 1 越好 |
| 反射系数 | reflection coefficient | 反射波与入射波之比 $\Gamma$，$|\Gamma|^2$ 是反射功率比 |
| 回波损耗 | return loss | 入射功率与反射功率之比的分贝值 |
| 失配损耗 | mismatch loss | 因反射而没能进入天线的那部分功率 |
| 增益 | gain | 某方向辐射强度相对参考天线的倍数，单位 dBi 或 dBd |
| 方向性 | directivity | 能量集中的程度，不考虑损耗 |
| 方向图 | radiation pattern | 各方向辐射强弱的图形，偶极呈 8 字形 |
| 波束宽度 | beamwidth | 功率降到一半（−3 dB）时两点间的夹角 |
| 前后比 | front-to-back ratio | 最大辐射方向与相反方向的功率差 |
| 极化 | polarization | 电场矢量的方向：水平、垂直或圆极化 |
| 效率 | efficiency | 辐射功率与输入功率之比，$R_{r}/(R_{r}+R_{L})$ |
| 辐射电阻 | radiation resistance | 等效的「辐射掉的电阻」，衡量结构把电流变成辐射的能力 |
| 损耗电阻 | loss resistance | 导体、线圈、地网与周围物体吸收功率的等效电阻 |
| 带宽 | bandwidth | 驻波或增益仍可接受的频率范围 |
| Q 值 | Q factor | 谐振陡峭程度，Q 越高带宽越窄 |
| 速度因子 | velocity factor | 电波在介质中的速度与光速之比，聚乙烯电缆约 0.66 |
| 特性阻抗 | characteristic impedance | 传输线自身的阻抗，同轴电缆常用 50 Ω |
| 仰角 | take-off angle | 辐射最强的方向与地面的夹角，决定单跳距离 |
| 菲涅尔区 | Fresnel zone | 收发之间必须保持通畅的椭球空间，被遮挡会损耗 |
| 镜像 | image | 地面反射等效出的「镜像天线」，用于分析架高对方向图的影响 |
| 共模电流 | common-mode current | 沿馈线外皮流动的电流，会引起干扰与驻波异常 |

## 四、天线类型速查

- **偶极（dipole）**：两臂各约四分之一波长，中心馈电，自由空间输入阻抗约 70–73 Ω。
- **倒 V（inverted-V）**：偶极两臂下折约 45°，只需一根支撑杆，代价是效率与带宽略有下降。
- **垂直（vertical）**：四分之一波振子加地网，辐射电阻约 36 Ω，靠地面镜像补成等效半波，低仰角好。
- **八木（Yagi-Uda）**：主振子加引向器与反射器，靠单元间的耦合形成方向性，是短波和 VHF 最常用的定向天线。
- **端馈（EFHW）**：半波长短线在一端馈电，需要高阻抗变换器与扼流圈。
- **偏馈（OCF/Windom）**：在偶极偏离中心处馈电，兼顾多波段，需要 4:1 或 6:1 变换器。
- **行波天线（T2FD、Beverage）**：终端接无感电阻，电流以行波形式前进，宽带但效率低于驻波天线。
- **环形（loop）**：小环靠磁场耦合、大环可自谐振；磁环天线适合空间受限的场合。
- **NVIS**：低架水平天线靠高仰角天波覆盖几百公里，用于区域通信。

## 五、小结

> **只记一件事**
>
> 天线术语分三层：结构与部件（振子、巴伦、地网）、电性能（阻抗、驻波、增益、极化、效率）、天线类型（偶极、垂直、八木、端馈、环形）；考试最爱考的缩写是 DP、GP、VER、LW、YAGI、BEAM 与 EL。
