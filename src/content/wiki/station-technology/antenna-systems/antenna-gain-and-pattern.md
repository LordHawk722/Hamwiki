## 一、增益：dBi、dBd 与方向图

&emsp;&emsp;增益（gain）回答的是“能量往哪个方向集中、集中了多少”，它是方向性系数与效率的乘积。读增益数字之前，先把分贝（decibel，dB）搞清楚，因为增益、损耗、前后比都用它表示。分贝是两个功率之比的对数：

$$
\mathrm{dB} = 10\log_{10}\frac{P_{\text{out}}}{P_{\text{in}}}
$$

&emsp;&emsp;这组换算值得背到条件反射：3 dB 是两倍，10 dB 是十倍，-3 dB 是二分之一，-10 dB 是十分之一。于是 20 dB 等于 $10^{2} = 100$ 倍，60 dB 等于 $10^{6}$ 倍；反过来，功率放大到 100 倍就是 20 dB，放大到一百万倍就是 60 dB。5 倍约 7 dB，减半约 -3 dB。增益和损耗用同一把尺子：放大器“20 dB 增益”指输出功率是输入的 100 倍；“20 dB 损耗”指 99% 的功率变成了热。

| 分贝 | 功率比 | 常见说法 |
| --- | --- | --- |
| +3 dB | 2 | 翻倍 |
| +6 dB | 4 | 四倍 |
| +10 dB | 10 | 十倍 |
| +20 dB | 100 | 一百倍 |
| +30 dB | 1000 | 一千倍 |
| -3 dB | 0.5 | 减半 |
| -10 dB | 0.1 | 十分之一 |

&emsp;&emsp;表里的数字不必逐条背，记住 3 dB 和 10 dB 两个锚点就够用，其余都能由这两个拼出来。

&emsp;&emsp;分贝还有一处容易错：功率比用 $10\log_{10}$，电压或电流比要用 $20\log_{10}$。输出电压是输入的 100 倍，电压增益是 $20\log_{10}100 = 40$ dB；输出功率是输入的 100 倍，功率增益才是 $10\log_{10}100 = 20$ dB。因为功率正比于电压的平方，取对数后系数就从 10 变成 20。

&emsp;&emsp;dB 是相对值，单独一个 dB 没有绝对大小，所以增益后面必须说明参考对象。以各向同性点源（isotropic radiator）为参考，单位写作 dBi；以自由空间半波偶极为参考，单位写作 dBd。理想点源把功率均匀撒在整个球面上，现实中造不出来，作为参考点很方便；半波偶极在最大方向上的增益约 2.15 dBi，两种单位的换算只差一个常数：

$$
G_{\text{dBi}} = G_{\text{dBd}} + 2.15
$$

&emsp;&emsp;0 dBd 就是 2.15 dBi，5 dBd 就是 7.15 dBi。同一副天线用两种单位标，数值只差 2.15，放进同一张表里比较，却很容易被当成两副天线的真实差距；所以看参数表先确认单位，再把数字拉到同一口径上。考试常给 dBd 让算 dBi，记住 dBi 的数值更大就不会弄反。

&emsp;&emsp;实际比较时先统一单位再相减。比如甲天线 4.5 dBd、乙天线 5.85 dBi：把甲换成 6.65 dBi，比乙高 0.8 dB，远处接收到的信号功率也就高约 0.8 dB。

&emsp;&emsp;增益的来源是方向性，不是放大。无源天线的总辐射功率不会超过送入的功率，它只是把能量压进更窄的方向：同样 100 W，主瓣越窄，那个方向上的功率密度越高，增益也越高。增益是某个方向上的值，参数表标的通常是最大值；偏离主瓣，增益迅速下降，零点方向甚至收不到。它和放大器的“增益”同名却不是一回事——放大器真的把功率放大了，天线只是把同样的功率重新分配。

&emsp;&emsp;描述这种分布的是方向图（radiation pattern）。把天线在各方向的辐射强度画成曲线就得到方向图：能量最集中的一瓣叫主瓣（main lobe），旁边的小瓣叫旁瓣（side lobe），瓣与瓣之间的零辐射方向叫零点（null）。方向图的宽度用波束宽度（beamwidth）表示，通常取功率降到最大值一半（-3 dB）时两点之间的夹角，所以也叫 -3 dB 波束宽度。半波偶极在包含导线的平面内波束宽度约 78°，在垂直于导线的平面内则接近全向——两个平面要分开看，这也是方向图常画两张的原因。

![图 3-3 偶极的方向图：含导线平面呈 8 字形，垂直导线平面接近全向](/images/ant-dipole-pattern.png)

&emsp;&emsp;波束宽度与增益是一笔交换：同样的功率，主瓣压得越窄，最大方向的功率密度越高，增益也越高；反过来，波束宽、覆盖广的天线，单个方向的增益就低。定向天线还要看前后比（front-to-back ratio）：最大辐射方向与相反方向的功率差，单位 dB。增益和前后比是两笔账，增益高不等于背后干净；一副增益不低的八木，若前后比差，从后面收进来的干扰可能比正面的信号还强。

&emsp;&emsp;下面这张表给出几种常见天线的典型增益，用来校准数量级。它们都是自由空间里的峰值，实际装到塔上、靠近地面之后会变。

| 天线 | 典型峰值增益 |
| --- | --- |
| 半波偶极 | 2.15 dBi（0 dBd） |
| 2 单元八木 | 约 5–6 dBi |
| 3 单元八木 | 约 7–8 dBi |
| 5–6 单元八木 | 约 10–11 dBi |

&emsp;&emsp;表里最值得注意的是“单元越多、收益越小”：3 单元到 4 单元大约多 1 dB，5 单元往上每加一个单元往往不到 1 dB，而重量、风载和成本都在涨。增益不是免费的，它用尺寸、指向精度和带宽换。

&emsp;&emsp;读增益数字还要注意三点：一是参考对象，dBi 还是 dBd；二是这个数字是自由空间里的峰值，还是装到塔上、靠近地面之后的实际值，架设环境会让方向图变形；三是标称增益只描述天线这个部件，不含馈线损耗和失配损耗。把这三个前提对齐，参数表上的数字才可以互相比较。

## 二、极化与效率

&emsp;&emsp;极化（polarization）指电场矢量的方向，由天线的结构和架设姿态决定。水平架设的偶极辐射水平极化，垂直天线辐射垂直极化；卫星通信和部分甚高频（VHF）、特高频（UHF）通信用的是圆极化（circular polarization），电场方向在一个周期里旋转。

&emsp;&emsp;收发两端的极化对不上，就要付代价。同为水平或同为垂直，损失很小；一横一竖，理论上功率全部损失——来波的电场方向与接收天线垂直，推不动电荷；实际因为反射、散射和天线不理想还有少量耦合，但通常也要损失 20 dB 以上。圆极化与线极化之间固定损失 3 dB；左旋与右旋圆极化之间理论上也是全部损失。短波天波穿过电离层时极化会旋转（法拉第旋转，Faraday rotation），所以远距离短波对极化不敏感；本地通信、卫星和直射路径上，极化必须对齐。各种组合的细节和有效辐射功率的算法，可参见《极化与有效辐射功率》一节。

&emsp;&emsp;实际天线很少是“纯”线极化或“纯”圆极化，多数是椭圆极化：电场矢量画出一个椭圆，长轴与短轴之比叫轴比（axial ratio）。轴比越接近 1，越接近圆极化；轴比很大时，实际上就是线极化。交叉极化分量通常用 dB 表示，工程上希望它比主极化低 20 dB 以上。

&emsp;&emsp;最后一个参数是效率（efficiency）。增益其实是方向性系数（directivity）与效率的乘积：

$$
G = D \times \eta
$$

&emsp;&emsp;这里的 $G$、$D$、$\eta$ 都是线性值，不是分贝。方向性系数只描述能量聚得多窄，假设天线没有损耗；效率描述有多少功率真正辐射出去，即 $P_{\text{rad}}/P_{\text{in}}$。两者相乘才是实际增益，换成 dB，乘法就变成加法。

&emsp;&emsp;效率的去处可以逐项列：辐射电阻把电流变成辐射，损耗电阻把电流变成热。导体自身的电阻、加感线圈的铜损和磁损、地网和土壤里的损耗、附近物体吸收的能量，都记在损耗这一边。缩短天线时辐射电阻按长度平方下降，损耗电阻却不跟着降，所以“短而有效率”很难同时做到；加感线圈补的是电长度，不是效率。半波偶极架到合适高度，效率可以做到 90% 以上；短天线、加感天线、地网不良的垂直天线，效率常常只有百分之几十甚至百分之十几。

&emsp;&emsp;换算成分贝，效率 50% 是 -3 dB，25% 是 -6 dB，10% 是 -10 dB：

$$
\eta_{\text{dB}} = 10\log_{10}\eta
$$

| 效率 | 分贝 | 含义 |
| --- | --- | --- |
| 100% | 0 dB | 理想，功率全部辐射 |
| 50% | -3 dB | 一半功率变成热 |
| 25% | -6 dB | 四分之三变成热 |
| 10% | -10 dB | 九成变成热 |

&emsp;&emsp;这个量级比失配损耗的零点几 dB 大得多，也比 dBi 与 dBd 混用造成的 2.15 dB 大得多。所以看一副天线，顺序应当是：先看效率，再看增益，最后才是驻波。低驻波只说明能量进得去，低效率说明能量进去以后大多变成了热；增益是在效率之上再乘方向性。驻波表测不出效率，这是它最大的盲区。

&emsp;&emsp;效率也不容易直接测。业余条件下只能用场强比较、功率计加假负载，或同样功率下对方报告的信号强度来间接判断；这些方法都要控制变量，否则测到的是传播和噪声的起伏。天线分析仪能给出谐振与匹配，也给不出效率。

&emsp;&emsp;还要提醒一句：标称增益是某个方向的相对值，不是总辐射功率。增益高说明那个方向集中，不等于整副天线辐射得多，也不等于链路好——馈线损耗、失配损耗、架设环境都不在标称增益里。反过来，一副标称增益不高的全尺寸偶极，只要效率高、架得够高，实际效果常好过参数漂亮但损耗大的短天线。

## 三、小结

> **只记一件事**
>
> 增益是方向性乘效率，dBi 的数值比 dBd 大 2.15；效率差几分贝，比驻波差的零点几分贝重要得多。
